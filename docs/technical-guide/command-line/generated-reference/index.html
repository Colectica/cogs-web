CLI descriptor reference#

This reference is generated from the descriptors that configure the COGS command-line parser. It is checked in so documentation builds do not need to execute the tool, and CI rejects drift between this file and the executable.

cogs-new#

Create a model skeleton in a new target directory

Usage#

cogs cogs-new targetLocation [options]

Arguments#

targetLocation

Directory where the model skeleton is generated.

Options#

-?|-h|--help

Show help information

-o|--overwrite

If the target directory exists, delete and overwrite the location

publish-cs#

Publish a C# class structure from a COGS data model

Usage#

cogs publish-cs [cogsLocation] [targetLocation] [options]

Arguments#

[cogsLocation]

Directory where the COGS datamodel is located.

[targetLocation]

Directory where the c# schema is generated.

Options#

-?|-h|--help

Show help information

-n|--namespace <value>

URI of the target XML namespace

-o|--overwrite

If the target directory exists, delete and overwrite the location

--csproj

Determines whether to generate a .csproj project file

--nullable

Determines whether to use C# nullable types

publish-dot#

Publish a dot schema from a COGS data model

Usage#

cogs publish-dot [cogsLocation] [targetLocation] [options]

Arguments#

[cogsLocation]

Directory where the COGS datamodel is located.

[targetLocation]

Directory where the dot schema is generated.

Options#

-?|-h|--help

Show help information

--dot <value>

Path to the Graphviz dot executable. Uses COGS_DOT, then PATH when omitted.

-o|--overwrite

If the target directory exists, delete and overwrite the location

-f|--format <value>

Specifies format for output file. Defaults to svg

-a|--all

generate one graph containing all objects. Cannot be used with -s

-s|--single

generate a graph for every single item (incoming links and outgoing links). Cannot be used with -a

-i|--inheritance

allow inheritance in the graph(s)

-c|--composite

show composite types inside item types
